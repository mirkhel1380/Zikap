How to use the checker

  • Open a page in your desktop browser and select View page source, or use Ctrl+U.
  • Copy its HTML into the editor, or upload a saved .html file smaller than 2 MB.
  • Choose Analyze HTML. Read the explanations as well as the pass count.
  • Download the text report and use it to plan a more detailed review.

What the ten checks mean

The tool checks title presence, approximate title length, description presence, approximate description length, a single H1, heading sequence, image alt attributes, viewport settings, an absolute canonical reference, and noindex instructions in the robots meta tag.

Some checks are style and accessibility heuristics. Heading order and the number of H1 elements are not direct ranking scores. An image-free page passes the alt check as not applicable. Empty alt text is allowed for decorative images; the tool cannot judge whether a description is useful.

Read results in context

The score is simply the share of checks that passed. It does not measure search visibility, content quality, accessibility compliance, or Google’s view of the page. Character ranges are rough editorial guides, not requirements.

This tool does not fetch a URL, crawl a website, execute the uploaded scripts, inspect response headers, test links, or measure performance. It cannot confirm indexability from HTML alone. A wider audit needs live website evidence and a separate scope.

PACKAGE QUESTIONS

Clear before
you start.

Are these monthly subscriptions?

No. These are one-time starter project prices in USD. Ongoing work requires a separate scope.

Will you edit my live website?

The listed starter prices cover reports and proposed edits. Direct website publishing, development, and implementation are quoted separately and require the appropriate access and agreed responsibilities.

Does keyword research include live metrics?

The $19 package covers curated keyword ideas, intent grouping, and page mapping. Search volume, difficulty scores, and live rankings are not included. If needed, data-provider research is scoped separately.

Can I buy these packages online now?

The package button opens the project request workspace, which displays current availability. A request needs acceptance before work starts. Online payment is not enabled.

Which tools can I use for free?

Yes. Yes. HTML checking, search snippet preview, and keyword list organization are free. Paid packages provide separately scoped specialist work and tailored deliverables.

What if I need a larger project?

Prepare a request describing the extra pages or work. A broader scope and price must be agreed before work starts; extra services are not silently added.

01 / TECHNICAL SEO

From an observation
to a verifiable action.

Fictional garden shop · example.com · invented findings for demonstration.

SAMPLE ACTION REGISTERILLUSTRATIVE
T-01 / DISCOVERY

An important page lacks an internal link.

In this fictional scenario, a category page has no contextual link from a related page.

Recommended action
Add a descriptive link where it helps visitors reach the relevant category.
Suggested owner
Content editor
Verification
Confirm the link is useful and resolves directly to the intended page.
T-02 / URL CLEANUP

An internal link follows old URL changes.

The sample link uses two intermediate destinations before reaching the intended page.

Recommended action
Review dependencies, then update the internal link to the correct final URL.
Suggested owner
Developer or website administrator
Verification
Test the revised link and confirm existing redirects still serve their purpose.

The downloadable sample also includes a canonical-review example and handoff notes.

03 / ON-PAGE SEO

Give the page
a clearer job to do.

A suggested edit brief for a fictional product category. No edits have been implemented.

SAMPLE PAGE EDIT BRIEFILLUSTRATIVE
PAGE PURPOSE

Help a beginner compare the available kits and understand their practical requirements.

PROPOSED TITLEIndoor Herb Kits for Beginners | Example Garden
PROPOSED META DESCRIPTION

Compare indoor herb kits, see what each includes, and learn the light and care requirements before choosing a kit for your home.

Suggested content outline

  1. Compare the available kits
  2. What is included in each kit
  3. Light, space, and care requirements
  4. Choosing a kit for your home
  5. Common questions before buying

Product facts need verification. Proposed metadata does not guarantee how a search engine will present the page.

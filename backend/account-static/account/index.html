Open an English Queries.csv or Pages.csv from a single-period Search Console performance export. Extract the CSV from the downloaded ZIP first.

A snapshot you control.

  1. In Search Console, open Performance / Search results.
  2. Select one period and export as CSV.
  3. Open the Queries or Pages file here.

Up to 1 MB and 5,000 rows. English headings and numbers only. Comparison exports are not supported.

This tool reads a file you supply. It does not connect to Google, fetch rankings or upload your file. Imported data stays in memory until reload or sign-out.
